# phpnitro/firebase

The [PhpNitro](https://github.com/phpnitro/phpnitro) framework's Firebase package — a plain Firebase Auth REST client (`Engine\Firebase\*`), no Firebase SDK dependency.

This package is a read-only mirror, extracted from the main [phpnitro/phpnitro](https://github.com/phpnitro/phpnitro) monorepo — contribute there, not here.

## Installation

```bash
composer require phpnitro/firebase
```
